# UI/UX Design — Kapitel 1, version 1

## Tone og retning

En professionel, imødekommende og visuel introduktion til UI/UX. Fokus er på at forstå brugerens behov og bruge design til at skabe digitale løsninger, der er tydelige, brugervenlige og relevante. Hold hvert slide enkelt: én hovedpointe, korte tekster og konkrete eksempler.

## Slides

### 1. Titel — UI/UX Design
**Fra brugerbehov til brugervenlige løsninger**

Introduktion til, hvordan vi designer digitale oplevelser med mennesker i centrum.

### 2. Læringsmål
Efter kapitlet kan du:
- forklare forskellen på UX og UI
- beskrive, hvorfor brugerbehov er vigtige i design
- genkende grundprincipper for brugervenlige interfaces
- skitsere en enkel digital løsning ud fra en opgave

### 3. Hvorfor betyder design noget?
Gode digitale løsninger gør det lettere at forstå, finde og gennemføre det, man kom for. Utydelige valg og forvirrende navigation skaber frustration. Design handler derfor ikke kun om udseende — det handler også om, hvordan løsningen fungerer for mennesker.

### 4. UX og UI — to sider af samme oplevelse
- **UX (User Experience):** brugerens samlede oplevelse, behov, flow og forståelse.
- **UI (User Interface):** det visuelle interface — eksempelvis layout, typografi, farver og knapper.
- UX former oplevelsen; UI gør løsningen synlig og hjælper brugeren med at handle.

### 5. Grundprincipper for brugervenligt design
- **Tydelighed:** Brugeren skal kunne forstå, hvad der sker.
- **Konsistens:** Ens elementer bør fungere og se ens ud.
- **Enkelhed:** Vis det vigtigste uden unødvendig støj.
- **Feedback:** Giv brugeren besked, når en handling lykkes eller kræver opmærksomhed.
- **Tilgængelighed:** Gør løsningen anvendelig for så mange som muligt.

### 6. En enkel designproces
1. Forstå brugeren og situationen.
2. Afgræns behovet og problemet.
3. Skitsér mulige løsninger.
4. Byg en enkel prototype.
5. Få feedback, og forbedr løsningen.

Designprocessen er iterativ: Man lærer, justerer og prøver igen.

### 7. Eksempel — find vej i en webshop
**Udfordring:** En bruger har svært ved hurtigt at finde og købe en bestemt vare.

**Mulige designgreb:** Tydelige kategorier, forståelig søgning, synlige priser og en klar vej til kurv og betaling. Hvert greb skal hjælpe med brugerens konkrete mål.

### 8. Opgave — design en bedre digital oplevelse
Vælg en konkret situation, hvor en bruger møder et problem med en digital løsning. Foreslå en forbedring, der gør oplevelsen mere brugervenlig.

**Arbejd med:**
- målgruppe og situation
- brugerens behov og problem
- løsningens vigtigste trin eller skærmflow
- layout og visuel prioritering
- feedback: Hvordan kan du undersøge, om løsningen virker?

**Aflevering:** Lav en enkel wireframe eller prototype, og præsentér din idé. Forklar, hvilket brugerproblem du løser, og hvorfor dine designvalg hjælper.

### 9. Opsamling
- UX handler om den samlede brugeroplevelse.
- UI handler om det interface, brugeren møder.
- Gode designvalg tager udgangspunkt i brugerens behov.
- Skitser, test og forbedr — også når løsningen er enkel.
